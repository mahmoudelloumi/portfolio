Installer dans Gmail
  1. Clique sur « Copier la signature » ci-dessus.
  2. Gmail → ⚙️ → Voir tous les paramètres → onglet Général → section Signature.
  3. Créer, puis colle (Ctrl+V) dans la zone de texte.
  4. En bas de la page : Enregistrer les modifications.
Outlook
  1. Paramètres → Comptes → Signatures → nouvelle signature → coller → enregistrer.
